# Kho Tri Thức Người Dùng (User Knowledge Base)

Thư mục này được dùng để lưu trữ các tài liệu chuyên ngành do chính người dùng thêm vào:
- Định dạng hỗ trợ: `.pdf`, `.md`, `.txt`
- Bạn có thể đặt tài liệu trực tiếp vào đây hoặc tải lên qua giao diện Web (Streamlit UI).
- Hệ thống áp dụng cơ chế **Strict Grounding**: Chỉ trả lời dựa trên những gì có trong tài liệu bạn nạp vào đây.
